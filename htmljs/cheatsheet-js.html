DOM Cheat Sheet – JavaScript

Patrón clave: Selecciona → Recorre → Manipula

1. Seleccionar elementos del DOM

Por ID

const elem = document.querySelector('#miId');

Por clase

const elems = document.querySelectorAll('.miClase');

Por etiqueta

const inputs = document.querySelectorAll('input');
const divs   = document.querySelectorAll('div');

Por atributo

const passwords = document.querySelectorAll('input[type="password"]');

Dentro de un contenedor

const inputsForm = document.querySelectorAll('#formulario input');

2. Recorrer elementos

NodeList

forEach sobre el resultado de querySelectorAll

const elementos = document.querySelectorAll('li');

elementos.forEach(elem => {
  console.log(elem);
});
Convertir a Array

Spread operator

const elementos = [...document.querySelectorAll('li')];

3. Texto en elementos (div, p, h1…)

Obtener texto

const div = document.querySelector('#mensaje');
console.log(div.textContent);

Cambiar texto

const div = document.querySelector('#mensaje');
div.textContent = 'Nuevo texto';

4. Inputs: obtener y usar valores

Input individual

const input = document.querySelector('#nombre');
const valor = input.value;
console.log(valor);

Todos los inputs (recorrer)

const inputs = document.querySelectorAll('input');

inputs.forEach(i => {
  console.log(i.value);
});

5. Checkboxes & Radios

Checkboxes marcadas

const checks = document.querySelectorAll('input[type="checkbox"]');

checks.forEach(c => {
  if (c.checked) {
    console.log(c.value);
  }
});

Radio seleccionado

const seleccionado = document.querySelector('input[name="grupo"]:checked');

if (seleccionado) {
  console.log(seleccionado.value);
}

6. Select / Option

Value seleccionado

const select = document.querySelector('#miSelect');
const valor = select.value;
console.log(valor);

Texto mostrado en la opción seleccionada

const select = document.querySelector('#miSelect');
const texto = select.options[select.selectedIndex].text;
console.log(texto);

7. Cambiar estilos con JS

const elem = document.querySelector('#caja');

elem.style.color = 'red';
elem.style.border = '2px solid blue';
elem.style.backgroundColor = '#eeeeee';

En JS, muchas propiedades CSS con guion pasan a camelCase: background-color → backgroundColor.

8. Audio y multimedia

Pausar un audio

const audio = document.querySelector('audio');
audio.pause();

Pausar todos los audios excepto el que suena

const audios = document.querySelectorAll('audio');

audios.forEach(audio => {
  audio.addEventListener('play', () => {
    audios.forEach(a => {
      if (a !== audio) {
        a.pause();
        a.currentTime = 0; // volver al inicio (opcional)
      }
    });
  });
});

9. Crear un objeto con los valores del formulario

const datos = {};
const inputs = document.querySelectorAll('#formulario input');

inputs.forEach(i => {
  // usar el atributo name como clave
  datos[i.name] = i.value;
});

console.log(datos);

10. Validar campos vacíos

const inputs = document.querySelectorAll('#formulario input');
let todoOK = true;

inputs.forEach(i => {
  if (!i.value.trim()) {
    i.style.border = '2px solid red';
    todoOK = false;
  } else {
    i.style.border = '';
  }
});

if (todoOK) {
  alert('Todo OK');
}

11. Eventos típicos

const elem = document.querySelector('#boton');

elem.addEventListener('click', () => {
  console.log('Click');
});

elem.addEventListener('input', () => {
  console.log('Valor cambia mientras escribes');
});

elem.addEventListener('change', () => {
  console.log('Valor final cambiado (select, checkbox, etc.)');
});

12. Patrón general DOM

Patrón que se repite en casi todos los ejercicios: 1. Selecciona → 2. Recorre → 3. Manipula 

const elems = document.querySelectorAll('selector');

elems.forEach(e => {
  // leer propiedades: e.value, e.textContent, e.checked...
  // cambiar propiedades: e.textContent = '...', e.style...
});
